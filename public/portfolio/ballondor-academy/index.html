BALLONDOR ACADEMY

BallonDor Academy is a SaaS platform built for sports academies — the kind of software that handles enrollment, schedules, fees, and everything else a coaching academy needs to actually run as a business.

We built it end to end. That includes a working payment gateway so academies can collect fees online without chasing parents, and a backend that’s tuned to keep cloud costs reasonable as the user base grows.

We’re also handling marketing for them — running campaigns on Instagram and elsewhere. Their Instagram is at @ballondorsa — go take a look at the work we’ve been doing.

What we did: Full SaaS platform, payment integration, cloud cost optimization, ongoing marketing campaigns.
